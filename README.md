# Asteria — Unity project

Unity project source copied from the local `Unlimited` project and renamed for the Asteria game. Unity version: 6000.5.9f1.

Open this repository root from Unity Hub. Unity will regenerate `Library` and other local caches. The repository keeps `Assets`, `Packages`, and `ProjectSettings`; local caches, logs, and per-user editor settings are not versioned.

The project includes the current 2D character sprites, animation clips, scenes, physics setup, scripts, and package manifest. The project product name is set to Asteria.
